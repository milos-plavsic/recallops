## Incremental review

The release adds a CockroachDB distributed vector index prefixed by tenant, service, and embedding
space. Retrieval materializes an oversampled nearest-neighbor lane from that index, then joins to
the system of record and reapplies tenant, service, embedding-space, validity, and active-state
governance predicates before policy ranking. Two exact policy lanes remain, so approximate index
recall cannot silently remove the fail-closed evidence used for abstention.

The ordered schema change creates the replacement index online before dropping the legacy index.
The migration ledger records SHA-256 checksums, and managed-cluster plan evidence proves selection
of the replacement index. No remote call occurs inside a database transaction. Incident state and
the outbox row still commit atomically; derived S3 delivery remains outside that transaction in a
lease-protected least-privilege worker.
