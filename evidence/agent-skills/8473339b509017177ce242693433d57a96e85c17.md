## Remediation applied

The review confirmed that S3 outbox delivery must use a dedicated worker identity and remain
outside API database transactions. RecallOps therefore runs an independent outbox container with
its own least-privilege database secret; the API no longer performs delivery in its lifespan.
Local Compose uses the checksum-aware migrator rather than executing raw SQL files directly.

A fresh managed-cluster run then exposed that executing all schema files inside one transaction
prevented later files from reliably seeing public schema changes. The migrator now commits each
file separately while reacquiring the durable singleton lock and checking the immutable ledger.
A disposable clean database applied all 19 migrations successfully and was then removed.
