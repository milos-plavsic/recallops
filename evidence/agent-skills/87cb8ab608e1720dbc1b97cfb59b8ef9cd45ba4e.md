## Incremental finding and remediation

The live authenticated test of release `3ad1a09` found that CockroachDB requires `SELECT` on the
conflict target for the API's `INSERT ... ON CONFLICT DO NOTHING`. Broadening the API role would
have exposed outbox payloads. Release `87cb8ab` instead uses a plain insert inside a nested
transaction/savepoint. A duplicate incident replay rolls back only the duplicate outbox insert;
the surrounding incident transaction remains valid. The API retains `INSERT`-only outbox access.
