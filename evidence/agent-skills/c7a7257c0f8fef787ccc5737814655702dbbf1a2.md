## Incremental findings

The final change affects retrieval policy only: equally ranked memories corroborating the same
normalized action are treated as consensus, while equally ranked memories proposing different
actions still force `top_candidates_ambiguous` abstention. It introduces no database statement,
transaction, lock, retry, connection-pool, or schema change.

The existing transaction design remains aligned with the skill: incident state and the outbox row
commit atomically in one short database transaction; the S3 side effect runs later in the
least-privilege outbox worker; duplicate outbox inserts are isolated by a nested savepoint; SQL
constraints enforce tenant and workflow boundaries; and no remote call occurs inside a database
transaction.
